# Contributing

Before opening a pull request:

1. Describe the physical assumptions, units and boundary conditions affected.
2. Add tests for behavior changes.
3. Run `python -m unittest discover -s experiments/report_revision/tests -v`.
4. Keep generated data, weights, VTK files, logs and credentials out of Git.
5. Do not present expected or incomplete experiments as completed evidence.

Contributions are submitted under the repository's MIT License. Do not submit code or data you cannot legally redistribute.
